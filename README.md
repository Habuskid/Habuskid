## About

I build full-stack and Web3 products with a focus on stablecoin infrastructure, autonomous agents, privacy, and reliable onchain flows.

- Currently building [Murk](https://github.com/Habuskid/murk), a spending authority layer for autonomous agents on Celo.
- Recently built [Sedge](https://github.com/Habuskid/sedge), an AI financial copilot for stablecoin operations across Circle and Arc infrastructure.
- I like shipping products in this order: core logic, integration, end-to-end flow, reliability, UI, then polish.
- I care about products that work for real, not mock integrations or decorative demos.

## Selected builds

| Project | What it does | Stack / network |
| --- | --- | --- |
| [Murk](https://github.com/Habuskid/murk) | Spending authority layer that lets humans define financial limits while autonomous agents settle permitted machine purchases. | Celo, x402, Next.js, TypeScript, Neon |
| [Sedge](https://github.com/Habuskid/sedge) | Natural-language stablecoin copilot for swaps, bridges, transfers and balance workflows. | Circle App Kit, CCTP, Arc, Next.js, TypeScript |
| [Blindpot](https://github.com/Habuskid/blindpot) | Confidential no-loss savings protocol with encrypted balances, winner selection and claims. | Zama fhEVM, Solidity, Foundry, Morpho, Next.js |
| [Adyton](https://github.com/Habuskid/Adyton) | Confidential treasury vaults with cryptographic spending-policy enforcement. | Starknet, STRK20, Cairo, React, TypeScript |
